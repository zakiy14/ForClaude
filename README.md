# GMOコイン 外国為替FX 自動売買ボット (USD/JPY)

GMOコイン「外国為替FX API」(`https://forex-api.coin.z.com`) に接続して USD/JPY を自動売買します。
外部ライブラリ不要 (Python 3.9+ 標準ライブラリのみ)。

## ルール
| 項目 | 内容 |
|---|---|
| 通貨ペア | `USD_JPY` |
| 数量 | 最小取引単位 (API `/v1/symbols` の `minOpenOrderSize` を自動取得) |
| 利確 | 評価損益 **+2,000円以上** で即時成行決済 |
| 損切り | 評価損益 **-1,000円以下** で即時成行決済 |
| エントリー | 短期/長期移動平均(5/20ティック)の向きで成行新規。建玉は常に1つ |

※ 最小単位が 10,000通貨なら 1pip = 100円 → 利確 +20pips / 損切り -10pips 相当。

## 使い方
```bash
# 1) まずはドライラン (実注文なし・価格だけ取得して仮想売買)
python3 -m fxbot.bot

# 2) 本番
export GMO_FX_API_KEY=xxxx
export GMO_FX_SECRET_KEY=yyyy
DRY_RUN=0 python3 -m fxbot.bot
```
APIキーは GMOコイン会員ページで **外国為替FX用** に発行し、「注文」「建玉/約定照会」権限を付与してください。

## 環境変数
| 変数 | 既定値 | 説明 |
|---|---|---|
| `DRY_RUN` | `1` | `0` で実注文 |
| `TAKE_PROFIT_JPY` | `2000` | 利確額(円) |
| `STOP_LOSS_JPY` | `1000` | 損切り額(円) |
| `ORDER_SIZE` | 自動(最小単位) | 発注数量を固定したい場合 |
| `INTERVAL_SEC` | `1` | 監視間隔(秒) |

## テスト
```bash
python3 -m unittest discover -s tests -t .
```

## 注意
- 決済判定はボット側の監視(ポーリング)で行うため、急変時は閾値を超えて約定することがあります。
- ボットが停止すると決済も止まります。常駐実行(systemd 等)を推奨します。
- 投資は自己責任です。必ずドライラン・少額で動作確認してください。
